# 🇧🇷 CiSkeleton Language Pack — Brazilian Portuguese (Português do Brasil)

This repository contains the **Portuguese (Brazil) (Português do Brasil) language pack** for [CiSkeleton (CSK)](https://github.com/ciskeleton).

CSK uses a modular translation system where each language is maintained as an independent package for easier updates and community contributions.

## 📦 Contents

* CiSkeleton language files for the **Portuguese (Brazil) (Português do Brasil)** locale.
* CodeIgniter 3 language files under `language/brazilian/ci3/`.
* CiSkeleton language files under `language/brazilian/`.
* Admin translations under `language/brazilian/admin/`.

## 🌍 Language

| Property      | Value                                                 |
| :------------ | :---------------------------------------------------: |
| Language      | Portuguese (Brazil) (Português do Brasil)             |
| Locale        | `pt_BR`                                               |
| Tag           | `pt-BR`                                               |
| Flag          | 🇧🇷                                                    |
| Package       | `lang-brazilian`                                      |
| Base language | [English](https://github.com/ciskeleton/lang-english) |

## 🤝 Contributing

Translations are welcome. Please keep the repository structure and language keys consistent with the [English language pack](https://github.com/ciskeleton/lang-english).

## 📖 About CiSkeleton

[CiSkeleton (CSK)](https://github.com/ciskeleton) is a modular platform foundation providing multilingual support, an admin panel, extensibility, and other application-level features.
